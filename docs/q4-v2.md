# Toklet Q4 version 2 group 8 candidate

Freeze one separate group-8 affine Q4 candidate before new held-out evaluation.
This reduces the number of weights sharing each scale, at the cost of increased
metadata traffic. It is a reconstruction-error hypothesis, not a guarantee that
loss or latency improves. Q4 v1 bytes, policies and rejection evidence remain
unchanged. This candidate uses no calibration text or held-out parameter search.

## Packed matrix layout

V2 uses eight adjacent values per independent row-local group. Every group is
8 bytes: little-endian Half scale, Half bias, then four packed-code bytes.
The earlier feature is the low nibble. Codes remain four bits; metadata brings
storage to eight effective bits per weight before headers/padding, versus
v1's 4.5 bits. Row-major shape is `[out_features, in_features]`; row stride is
`align_up(ceil(columns / 8) * 8, 64)` bytes. Partial-group unused codes and row
padding are zero. Row starts are file-relative 64-byte aligned, with no pointer
alignment assumption for Rust byte slices. Metadata remains 4-byte aligned.

The 64-byte little-endian header retains v1 field offsets: magic at0 is
`TOKQ4V2` followed by zero, version at8 is2, group size at12 is8, rows at16,
columns at24, row stride at32, payload bytes at40 and sixteen reserved zero
bytes at48. All dimensions are positive; lengths/overflow/stride/reserved data
and noncanonical padding are rejected before reconstruction. No trailing data.
The quantizer identity is `toklet-q4-affine-f32-source-half-metadata-rne-g8-v2`.

## Numerical and provenance policy

Preserve [v1 numerical rules](q4-v1.md): decode sources to FP32 without an
intermediate Half cast; calculate valid-group extrema in FP64, bias=min and
scale=(max−min)/15; round metadata to Half ties-to-even; normalize signed zero;
retain the smallest Half subnormal for a nonconstant group whose scale rounds
to zero; reject nonfinite source/metadata and metadata overflow. Choose codes
with FP64 arithmetic and rounded metadata, ties-to-even and clipping0–15.
Constant groups have zero scale/codes. Reconstruct once to FP32 as
`FP32(scale)*FP32(code)+FP32(bias)` with no additional Half cast.
Smaller groups do not guarantee less error for every weight after metadata rounding.

The model manifest is `toklet-q4-model-v2`, with the v2 quantizer identity.
All v1 manifest fields, exact tensor inventory, source/config/shard/decoded-source
hash binding and exclusive destination ownership remain. Norms, Q/K/V biases
and the single tied embedding/output table stay Half. Manifest and every matrix
must have the same validated format; authenticated bytes do not excuse a mismatch.

[Model packing](../tools/quantization/model.py) selects `--format v2` explicitly;
v1 remains the default. It streams one source row and preserves endpoint hashes,
size bounds and cleanup policy. The [matrix packer](../tools/quantization/q4v2.py)
retains v1 arithmetic rules under distinct magic/version/group and policy.
The [Rust parser/oracle](../src/q4.rs) validates storage without allocation and
selects statically specialized scalar reconstruction outside matvec loops.
Artifact admission includes packed matrices, largest staging matrix,64MiB
metadata and64KiB conversion; callers must add exclusions and session/application
storage. Initial GPU loading refuses v2 before compilation/allocation until its
separate execution task is qualified.

## Frozen qualification sequence

First verify independent hand-calculated bytes/FP32 reconstruction and scalar
FP64 matvec, widths around8/64 boundaries, tails, constants, midpoint/subnormal
metadata, overflow, malformed bytes and manifest/matrix version mixing. Preserve
all v1 fixtures and tests. Freeze new independent reconstructed-graph fixtures
before Metal execution, using the existing independent gate formulas.

Then qualify bounded v2 compensated vector and eight-row prefill variants with
operation-boundary format selection, queried SIMD widths, no per-element format
branch or weight expansion. Keep Q4Compensated/Q4CompensatedTiled projections and
Compensated normalization: these are existing numerical mechanisms, not new
accumulation/normalization experiments. Preserve capacity/chunk/session and
failure recovery behavior. Validate both fixed geometries independently.

Only after independent numerical qualification, apply the unchanged short
batch/single consistency guards, full10,000-target loss increase≤0.05 and
100-task drop≤2percentage points against matched FP32. Evaluate this candidate
once; no iterative grouping/metadata tuning against the held-out results.
A failure remains a rejection. Measure complete controlled/application/sustained
workloads and confirm a declared vector/tile comparison before accepting a gain.
Original and v1 defaults remain; M5 closes only with all required exit evidence.
Astra accepted the design rationale and qualification sequence before implementation.
