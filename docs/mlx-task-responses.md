This task creates explicit derivatives for later grading; it executes no generated program and starts no VM.

The [adapter](../tools/experiments/m8_task_responses.py) replays both original complete console streams through the strict task validator and authenticates the immutable collection, model, native package, signed app and tokenizer. Its raw JSONL derivative preserves each original app marker and JSON substring, with a link to the full source evidence; it does not invent legacy CLI events. It repeats after decoding and preserves command failure, cleanup and diagnostic-capture causes separately. Remote PIDs never enter host process checks. The barrier never launches or terminates an app.
