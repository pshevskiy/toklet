# Source-bound Q4 model artifact

This completes the model-artifact prerequisite of M5.2, while GPU integration,
frozen quality and performance acceptance remain pending. The
[contract](../q4-v1.md) now specifies the model manifest and how it binds source
checkpoint/config, tensor shapes, quantizer and matrix payload identities.

The standard-library Python exporter streams one row at a time from single or
indexed F32/F16/BF16 safetensors. It quantizes only Q/K/V/O/gate/up/down. FP16
exclusions are loaded later from the source checkpoint, including a single tied
embedding/output allocation. A bounded CPU-only Rust inventory admits packed
weights plus the largest one-matrix staging allocation, metadata and a 64 KiB
conversion/hash buffer. Returned matrix bytes are rehashed and structurally
validated at use; no entire reconstructed model is allocated.

The frozen tiny source produces 14 matrices, 33,664 bytes total and a 4,160-byte
largest matrix. Packed-only load admission is 67,212,224 bytes. The pinned
Qwen2.5-0.5B source produces 168 matrices, 203,893,248 bytes total and a
2,490,432-byte largest matrix. Packed-only admission is 273,558,080 bytes.
These values exclude live FP16 weights, session and application buffers and do
not constitute full GPU model admission. The explicit Rust suite validates all
tiny and real matrices against independent known geometry and source hashes.

Validation: formatting, strict all-target Clippy and ordinary tests pass with
default features (83 passed) and Metal (87 passed; device/model tests skipped).
All 15 Python quantization/artifact tests pass. Checks use isolated
`artifacts/m5-checks`; no GPU/shader execution changes belong to this task.
Source and packed evidence is recorded in the
[artifact qualification record](../../benchmarks/results/2026-10-13-q4-artifact.json).

Astra found and reviewed fixes for source-identity ordering, bounded JSON reads
and unbounded layer inventory creation. Regression tests mutate config/header
between parsing and the former first hash, grow JSON after size inspection,
simulate a final manifest flush failure, and reject `usize::MAX` layer count
before allocation. Earlier complete matrices are retained after exporter failure,
but no usable manifest is published. Existing evidence is never overwritten.

The first local packing run preceded the provenance-order/read-bound fixes;
those fixes do not change quantized bytes. The independent Rust check verifies
its complete matrix/source identities and geometry under the final loader. The
Qwen source payload matches the original pinned SHA256
`fdf756fa7fcbe7404d5c60e26bff1a0c8b8aa1f72ced49e7dd0210fe288fb7fe`.
No generator-revision or end-to-end performance claim is made for that bootstrap
packing run.
