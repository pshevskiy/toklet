# Q4 format v1 qualification

M5.1 is complete. The [format contract](../q4-v1.md) specifies every stored byte,
source rounding, affine reconstruction and numerical edge policy. A standalone
Python packer streams FP32LE rows, retains source/payload identities and refuses
existing destinations. A feature-independent borrowed Rust parser rejects
malformed data before exposing weights and provides checked scalar FP64 matvec
over reconstructed FP32 values, without an expanded matrix.

The [frozen matrix](../../tests/fixtures/q4/manifest.json) contains two 65-column
rows. Its manually calculated first group exercises every code and nibble order;
constant tails and the second zero row exercise canonical padding and 64-byte
row alignment. Python repacking matches the entire file byte for byte. Rust
independently verifies the SHA, all reconstructed values and a hand-calculated
118.5 matvec result. Additional tests cover metadata Half rounding, signed zero,
subnormals, extrema, ties-to-even, overflow, corrupted headers, invalid lengths,
constant/tail padding and preservation of caller output on matvec failure.

Validation on Apple M1 Pro: `cargo fmt --check`, strict all-target Clippy and
ordinary `cargo test` pass both with default features (79 passed) and with Metal
(83 passed; hardware/model checks explicitly ignored). All seven standard-library
Python quantization tests pass. Builds use isolated `artifacts/m5-checks`; root
release binaries are untouched. There are no GPU execution changes in this task.

Astra reviewed the code and independently replayed the Python suite. The review
found one final buffered flush/close cleanup bug; the output context is now inside
the owned-file cleanup scope, with a regression test. Exclusive-open failure
preserves pre-existing files. Astra accepted the corrected code without remaining
findings.

This task establishes an engine-specific matrix format, not MLX compatibility,
model loading, quality or a performance claim. Norms, biases and tied embeddings
remain FP16 in the planned model representation. The model-level packer must bind
source checkpoint/config hashes and separately admit its full working set.
