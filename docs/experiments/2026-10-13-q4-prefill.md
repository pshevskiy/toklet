# Experimental eight-row Q4 prefill

The opt-in Q4 tile reduces warm 512-input/one-output time to first token by
35.1% and 35.2% in two quiet paired runs on Apple M1 Pro 16 GB, macOS 26.6.2,
AC power, low-power mode disabled. Original medians are 2.976649 and 2.975180
seconds; tile medians are 1.931330 and 1.927867 seconds. Ten alternating measured
pairs follow three warmups per run. Median absolute deviations are 0.9–1.5 ms
for Original and 2.7–3.0 ms for the tile. All paired full last-position
distributions have zero measured absolute difference; greedy IDs agree.
This supports retaining the experimental mechanism, not adopting
it by default or accepting Q4 quality.

One queried SIMD group computes an output row for up to eight prompt rows.
Adjacent lanes traverse adjacent packed columns and reconstruct each weight
once for eight independent FP32 accumulators. Output remains Half, including
checked overflow and original bias placement. Fixed accumulator indices allow
bounded compiler specialization. The dynamically indexed prototype was 28.5%
slower and is rejected. Register retention explains the revision's hypothesis;
it is not established by assembly inspection. No additional persistent tensors
or weights are allocated. Chunks below eight use the original Q4 matvec.

`Session::with_projection_mode(..., ProjectionMode::Q4Tiled)` selects once per
projection operation. Original remains default and Half models reject the Q4
option before session allocation. Resident weights, separate session KV/scratch,
completion, failure and pending-token publication retain their original rules.
Chunk admission remains at 128 and GPU geometry remains tiny/0.5B.

The frozen six-case independent fixture covers 7/8/9/17/24 rows and offset five.
The expanded independent decoder check **fails on both Original and tile**:
offset17 final normalization, row16 feature19, is 0.0899658203125 versus
0.090576171875, beyond the unchanged `1e-4 + 1e-3*abs(reference)` gate. Earlier
small Half rounding differences begin in layer0 gate/up; layer0 output agrees.
Layer1 attention projection crosses a Half midpoint and a residual chain
amplifies the difference. Both paths produce the same stage bits. This identifies
an inherited numerical limitation; it remains unresolved. No tolerance, fixture,
quantizer or quality policy was changed to hide it.

The separately runnable ignored test
`tiled_q4_prefill_matches_independent_oracle_at_all_stages_and_chunks` retains
that frozen gate and failing outcome. It is not part of a claimed passing
expanded numerical suite. A separate refinement check binds the packed artifact,
the exact unique stage inventory, chunk shapes and full value counts, then proves
bit equality in all 4,550 complete stage arrays across six cases and chunks
full/8/3/1. Queried widths are 32/32 on this device. Independent primitive tests
retain reconstructed-weight error bounds, 65-column tails, poisoned inactive
inputs, padding/output guards, metadata edge cases and checked Half overflow.
The previously qualified independent tiny Q4, Qwen projection/session and FP16
regressions pass. Refinement establishes preservation of Original on this device,
not expanded full-graph numerical correctness or portability of bit equality.

The worker shares one model between two capacity1024/chunk128 sessions. Combined
admission is 903,731,092 bytes, including a fixed 64 MiB application allowance.
Idle worker/driver lifetime charges are measured jointly and fit 6 GiB. Timings
include completed GPU work, final-logits readback and CPU greedy selection.
Sources, packed payloads, executable, workload, compiler, build and power
endpoints are bound in each run. Source snapshots differ after measurement only
in public API documentation, with numerical code unchanged; the binding records
the final checked build separately. This is an engine first-token experiment,
not the full output128 workload, application comparison or sustained release.

The [qualification binding](../../benchmarks/results/2026-10-13-q4-prefill-qualification-v1.json)
retains measurements, rejected prototype, independent failure and native checks.
Formatting, strict Clippy in both configurations, 86/93 ordinary Rust tests,
157 experiment Python tests and 20 reference Python tests pass. Astra reviews
code, verification and the explicitly experimental retention decision.

Chunk128/256/512/1024 sweeps, required full-graph numerical gates, matched larger
quality, dispatch experiments, complete workloads and sustained release evidence
remain pending. The 0.5B Q4 held-out rejection and CPU default are unchanged.
