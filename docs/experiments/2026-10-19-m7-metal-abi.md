# M7 explicit Metal native boundary

The native ABI adds an explicit Metal loader for the selected compensated Half
and frozen Q4 v2 models, retaining ABI 1 record layouts and CPU behavior. Shared
immutable model ownership and session drop order remain private and unchanged.
A coarse backend match selects a concrete generator once per request, outside
numerical loops. Model/session boxes allocate once and fit the tested 4 KiB
bridge reservation; no full FP32 reference model is loaded alongside GPU weights.

Half selects HalfCompensated/Original normalization; Q4 v2 selects
Q4CompensatedTiled/Compensated. Both use Online attention, FP16 KV and FullLogits.
Unsupported builds return an explicit status without fallback. V1 packed models
are rejected before publishing a handle, following the existing CLI loader
policy. CPU capacity remains at most2,048; Metal uses existing explicit model
and memory admission limits. Defaults and numerical kernels stay unchanged.

Portable tests add unavailable-backend rejection and a bridge allocation-layout
check. Existing ownership, callback, later-output-failure, hidden-stop, pending
continuation, cross-thread cancellation and panic tests remain. An explicit GPU
suite compares both native selected models with direct sessions sharing the
same resident weights, checking exact three-token IDs and7/6/1 history/committed/
pending state. Combined logical admission counts weights once across both
sessions. A separate compiled C Metal client matches the independent frozen tiny
oracle and exercises cancellation, reentry, continuation, reset and release.

The validation controller admits the exact two-model/config/196-packed-payload
inventory from the accepted M6 proof before launching. Current source, compiled
runner/client and qualified tiny loader fixture are pinned at both endpoints.
Owned workers have bounded deadlines and TERM/KILL cleanup/reaping; primary
failures, cleanup and endpoint errors remain in failed receipts/raw logs.
Six portable controller tests cover a real timeout/reap, natural-exit race,
bounded final reap, frozen-pin zero-launch mutation, failure endpoint recording
and bounded parsed metadata. Astra's controller findings were fixed before any
GPU launch. An initial read-only preflight also corrected Cargo's library target
kind selector for the rlib/staticlib package; no GPU test was skipped or inferred.
