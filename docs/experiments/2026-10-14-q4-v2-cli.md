# Explicit Q4 v2 CLI integration

The CLI can load the frozen v2 artifact explicitly, preserving CPU scalar,
Original Metal, Half modes, FullLogits and chunk128 defaults. This qualifies
CLI functionality; small v2 remains quality-rejected and larger release/task/
performance evidence is still pending.

## Interface and execution

Use `--backend metal --q4-weights PATH --metal-projection q4-v2-compensated-tiled`.
Both new options are required together, in either order. CPU use, missing values,
duplicates, missing partners and conflicting modes reject before model access.
Generic bounded artifact loading authenticates source/config/matrix inventory;
the explicit CLI boundary rejects an authenticated v1 artifact before any event.
Sessions select Q4CompensatedTiled and Compensated normalization once, with
resident immutable weights, session-owned Half KV/scratch and existing frontend
memory admission. No generation, pending/cache, cancellation or text algorithm
changes are introduced.

Ready and statistics report actual dtype, projection/normalization/readback,
chunk size, version2, group8 and the source-bound quantizer. The latter fields
are optional and omitted for CPU/Half, preserving their metadata shape.
Tokenizer/application allowance still deducts from the6GiB limit before load
and session allocation; full logical sums remain visible. Version2 uses four-bit
codes with eight effective bits per weight including metadata before padding.
