# Explicit Q4 v2 held-out scorer integration

The scorer explicitly selects the one frozen Q4 v2 candidate on both pinned
checkpoints. This task qualifies scorer integration and unchanged short guards;
full-corpus loss, task quality and speed remain separate.

## Behavior and boundaries

[The scorer](../../examples/metal_quality.rs) accepts
`q4-v2-compensated-tiled` only with a validated v2 packed artifact. It uses
Q4CompensatedTiled projection and Compensated normalization, reporting the actual
format, quantizer, queried widths and resident dtype/memory. Existing Half/v1
calls keep their selection and numerical behavior. Ordinary CPU/default paths
remain unchanged.

[The separate collector](../../tools/experiments/metal_quality_v2.py) binds the
accepted real-geometry receipt, all consumed packed/reference bytes, source,
config, corpus, baseline, contract, executable, engine and helper sources.
It reuses the existing bounded owned transport and all-row causal loss checks,
with independent v2 configuration and residency admission. Initial/final
identities and worker+driver native lifetime charges are required.

The two original four-token probes run at chunks1 and128 before any full worker.
Expected ordered names, tokens and token-byte hashes derive from exact bounded
SHA-checked frozen manifest bytes before the helper runs. Both models reject
changed returned metadata before any child; the larger also matches its pinned
FP32 baseline. Source logit payload endpoints are bound. The1e-3 batch/single
NLL guard and0.05 full mean-NLL gate are unchanged. Partial probe/worker evidence
survives errors. Probe completion is distinct from full loss and quality
completion; a complete numerical collection can record a failed quality gate.

## Checks and native evidence

22 portable loss-collector checks pass, including both-model mode/format/
quantizer/geometry/residency rejection, metadata mutation with zero child
launches, failed-worker and guard-before-full ordering, partial evidence,
matched larger references and exclusive destinations. The initial test had an
incorrect mocked call-argument index; the corrected assertion checks chunk1/128
ordering. Ordinary Metal-feature Rust tests, all-target Clippy, formatting and
optimized scorer build pass.

Astra found missing probe manifest endpoint bindings and asymmetric prelaunch
metadata validation. Exact-byte admission, both-model tuple checks and mutation
regressions resolve those findings; source clearance preceded native runs.

Both original short guards pass, four clean owned workers and34 replayable
events per model. All input/source/binary endpoints remain unchanged.
