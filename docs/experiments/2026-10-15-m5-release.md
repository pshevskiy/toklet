# M5 performance release decision, 15 October 2026

M5 is complete for the qualified Apple M1 Pro configuration. Retain the small checkpoint's compensated Half path and the frozen larger checkpoint's group8 Q4 v2 path as explicit choices. Larger v2 passes the unchanged loss/task gates and confirms a useful tiled-prefill gain beyond noise. All required controlled/application, capacity/state, repeated and sustained evidence is complete. This supersedes the open-exit conclusion in the [14 October synthesis](2026-10-14-m5-performance-decision.md); it preserves that report's baseline limitations and rejected experiments.

CPU scalar, GPU Original projection, FullLogits and chunk128 defaults stay unchanged. Small Q4 v2 and both Q4 v1 candidates remain rejected. There is no automatic fallback, external speed-lead claim or default replacement. M6/M7 remain pending.

## Retain/reject decisions and baseline limits

Retain bounded required-row logits, exact-prefix cache reuse, the qualified compensated paths and useful v2 tile refinement. GPU greedy remains explicit for verified readback/storage effects; its measured latency is0.289% slower. Residual/RMS, rotary/cache and SiLU/gating fusion prototypes were removed after failing the gain threshold. Chunk256/512 gains stay below5%;1,024 regresses, so chunk128 stays. Preserve all numerical/quality rejections and the [improvement record](../improvements.md).

No newly alternating same-representation CPU/Metal primary comparison or full quality/memory-qualified FP16 external matrix exists. Historical small FP32 application emits different IDs; the larger standard FP32 application exceeds budget. The raw larger FP32 task-reference exception is not a standard application baseline. Historical small Half boundary decode is slower than CPU FP32; the prior report preserves the separate-representation context. Baseline gaps are disclosed as allowed by PLAN's M5 exit; no external lead/default replacement follows. ANE acceleration remains unobserved, with no adopted ANE backend.
