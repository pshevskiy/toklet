# Q4 v2 GPU vector and prefill qualification

The separately frozen group-8 Q4 candidate now executes through resident
compensated vector and eight-row prefill kernels. Both pass the complete tiny
independent graph and session checks. V1 kernels, artifacts and rejection evidence
remain; this task does not qualify v2 on either real checkpoint or accept its
held-out quality, latency, sustained behavior or M5 exit.

[The candidate contract](../q4-v2.md) keeps existing source/rounding/exclusion and
compensated arithmetic rules. [Two bounded shader variants](../../src/metal/kernels.metal)
use group8/record8 addressing, with no per-weight version branch. The
[immutable tensor format](../../src/metal/mod.rs) selects the kernel once per
operation. Only compensated vector/tile projection plus compensated normalization
are admitted for v2; incompatible defaults/modes reject before session allocation.
The GPU loader calculates packed weights/staging from admitted format, validates
manifest/header agreement and source endpoints, and retains no expanded model.

Each kernel reconstructs FP32 affine values in registers and preserves explicit
product residuals, two-component accumulation, bias-last order and midpoint-aware
Half storage. Adjacent lanes traverse adjacent input columns. SIMD widths are
queried independently for vector and tile; both are32 on this M1 Pro. The tile
reuses each reconstructed weight across eight token rows and masks inactive rows.
Resident KV/scratch/ownership, checked status, one completed command per chunk
and transactional publication remain unchanged. There is no new fusion mechanism.

## Independent reference and native results

The new [scalar oracle](../../tools/reference/q4_v2_tiny.py) reconstructs bytes
independently of the production packer and freezes six cases/210 complete arrays
before GPU use. Original oracle sources/fixtures remain unchanged. The manifest
SHA is `39dfd6e8580fc0d30fd1ee7795ab3a323cabfb63ea98e2eb889c607e7d6aaf25`.
[Offline tests](../../tools/reference/test_q4_v2_tiny.py) regenerate every fixture
byte from committed tiny source arrays without downloaded models or a GPU.

Astra found incomplete inventory and hash/read admission gaps in the new exporter.
Exact unique names/files/shapes/exclusions/source/config checks, bounded consumed
byte hashing and endpoint checks before manifest publication close both. Six
inventory mutation variants reject before forward; three replacement variants
reject ordinary publication before/after byte consumption. Draft exports are
retained under ignored artifacts and excluded; all independent numerical arrays
and gate formulas remain unchanged. The final exporter uses the original
`max(1e-4,2*independent_FP32_FP64_envelope)+1e-3*abs(reference)` formula.

On Apple M1 Pro/MacBookPro18,3/16GiB/macOS26.6.2(25G83), optimized Rust1.90.0 builds:
