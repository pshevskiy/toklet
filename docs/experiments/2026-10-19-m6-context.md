# M6 complete context qualification

All 32 frozen context roles pass replay: two selected models, four total-token
depths, and quality, profile, ordinary boundary and independent confirmation
plans. This closes context numerical, state, memory and boundary coverage.
The final FP16 KV retention and M6 decision are recorded separately.

## Scope and numerical checks

The Apple M1 Pro (MacBookPro18,3, 16 GiB), macOS 26.6.2 (25G83), Rust 1.90.0
release workers use compensated Half for Qwen2.5-0.5B-Instruct and frozen
group8 Q4 v2 compensated tiled projections/normalization for Qwen2.5-1.5B-Instruct.
Both use FP16 KV, chunk 128 and FullLogits. Immutable weights are shared;
Reference and Online sessions own separate KV and scratch.

The frozen cyclic held-out stress input reserves 128 output positions at each
depth: the maximum case has 32,640 prompt tokens and 32,768 total tokens.
It qualifies these numerical/state cases, without establishing natural
long-document ability. The [complete long quality report](2026-10-16-m6-full-long-quality.md)
covers 128 targets per depth, 512 per model. Every depth and pooled mean passes
the unchanged +0.05 NLL gate. Pooled Online-minus-Reference attention deltas are
-0.00001851999728900924 small and -0.0001262955813478074 larger, using the same
selected weights and FP16 KV. The matched FP32 10,000-target gate is separate.

Only the two original larger4K winner changes require manual investigation.
The [exact-case review](2026-10-16-m6-winner-investigation.md) resolves them
through pinned record/model/depth/index, prefix and full-distribution hashes.
Original automatic unresolved flags remain false. No tolerance or quality gate
changes, general near-tie exemption or new winner case is admitted.
