# Historical experimental Llama3 Mac app route

The opt-in route below was superseded by [default bounded Mac adoption](llama3-mac-adoption.md). Its historical evidence remains unchanged.

Launch the Mac app with `--experimental-llama3` to add the pinned Llama3.2 1B
profile to Models and Hugging Face matching for that process. The ordinary
catalog remains four profiles; iOS excludes this experimental profile. The row
shows incomplete accuracy qualification and its512-token limit. This is a
developer route, pending the original10,000-target/100-task adoption gates.

Opening through Models requires the audited loader, complete tokenizer and
strict native identity. The logical numerical/text/process budgets are2GiB,
256MiB and3GiB; they are admission policies, not measured whole-device fit.
An ordinary folder-open attempt rejects Llama before workspace saves or model
teardown and directs the user to Models. It invalidates stale planning previews
but preserves the chat, native owner, session and token history.

Checks cover default/flagged catalog, search, strict identity mutations, distinct
preference namespaces, all three unsigned app platforms and an actual cached Mac
controller. The controller sends, invokes the UI Stop action, recovers, rejects
ordinary folder open without damaging the chat, reopens a new audited owner and
preserves other-profile preferences. Its asynchronous cancellation observed
history47/evaluated47/pending0 and one emitted ID791. This is valid: cancellation
after evaluation can commit the emitted token. Synchronous callback cancellation
retains the stricter pending1 check in native tests. The initial controller test
expected pending1 and remains preserved as a failed test expectation.

A separate isolated rendered Mac fixture uses the actual experimental flag and
production views. Models shows the saved experimental row and notice; Use model
opens the verified cache at512; Send produces the visible reply “Hello.” Normal
app data is untouched. UI monitor values are not benchmark measurements.

No new physical phone runtime, fresh network download, full adoption quality,
larger context or throughput qualification is claimed.

[Evidence](../benchmarks/results/2026-11-03-llama3-mac-app-v1.json).
The coherent40-export package is selected only after guarded adoption checks;
the prior native39 package is preserved.
