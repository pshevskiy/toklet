# Full eight-bit native-app task response collection

This experiment collects the original 100 frozen task responses from the selected [loss-qualified eight-bit Qwen checkpoint](mlx8-full-loss.md) through the existing native Apple app coordinators on M1 Pro and iPhone 14 Pro. Collection and outcome grading remain separate. No tokenizer is constructed, no visible text is interpreted and no generated program is executed during this experiment.

The sealed task payload preserves every original case ID, literal prompt token sequence, full output cap and hidden stop policy. Coding cases retain their 256-token limit; other original caps remain unchanged. Capacity is 562 and prefill chunk size 128. The shared [strict task validator](../tools/experiments/m7_physical_tasks.py) checks all chunks, visible IDs, sampled/committed/pending counts, exact hidden stops, clocks, memory admission and a zero-state acknowledgement after every case. Mac validation uses its explicit installation-proof scope; phone validation retains signed installation/foreground proof.

The collector binds the exact compiled Mac runner/native package, current host helpers, immutable model inputs and previously accepted 10,000-target loss qualification. It stages one identical full task set, collects Mac responses to natural exit, then obtains a fresh same-device tiny storage observation before copying and collecting on the signed iPhone app. Both complete task streams are replayed from their exact captured bytes before evidence publication. Cross-device disagreements are recorded rather than assumed absent or repaired.

Both devices complete all 100 responses in 123 chunks, yielding 6,520 visible IDs and 66 hidden stops each. Every paired visible-ID sequence, hidden stop/reason and sampled/committed/pending/chunk count agrees exactly. These are raw response agreements, not decoded-text or graded-outcome equivalence yet.

Observed native lifetime peaks are 631,620,640 bytes on M1 Pro and 644,466,768 bytes on iPhone 14 Pro. Low Power Mode is off; recorded thermal states are zero on Mac and zero/one/two on phone. No representative or sustained performance qualification follows. Five owned collection commands and 45 transport commands pass (41 device operations and four boot queries). Seven natural absence endpoints and one identity-checked initial preflight reset end absent, with no cleanup or endpoint errors.

The publisher replays both complete strict validators and retains 94 raw files, 75 source copies and 389 current/source/private bindings through exclusive publication.
