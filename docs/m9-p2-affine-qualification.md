# M9 P2 qualification plan

Use the reviewed affine8 candidate and frozen P1 comparison. Repeat the
unmodified release benchmark in fresh owned Mac processes. Require the
same useful-gain threshold and examine every regression control with the
raw samples and environment. [P1 comparison](m9-p1-affine-prefill.md).

1. Replay the original 10,000-target loss recipe with chunk 1, capacity
   1,025, original block resets and the unchanged 0.05-nat gate. Compare
   target logits and greedy decisions to the accepted Mac collection.
   Separately score those same targets at chunk 128 in paired baseline
   and tile sessions. Verify active tile dispatch and bitwise complete
   distributions, then apply the unchanged loss threshold to this schedule.
   [Frozen loss](mlx8-full-loss.md).
2. Use the frozen 100 task prompts, original output caps and stops,
   chunk 128 and capacity 562. Compare decisions, full distributions
   at generation boundaries, committed state, stop and literal completions.
   Reuse the accepted grading only after verifying the archived source
   and exact completion identity. Otherwise run the qualified isolated
   grader with the original policy. [Frozen tasks](mlx8-full-task-quality.md).
3. Verify capacity, reset, changed prefix, pending token, cancellation
   and failed-candidate recovery with eligible tiled prefill. Charge
   the compiled pipeline and measure process peaks. Require a scoped
   candidate-enabled Mac app journey before changing managed eligibility.
   Physical iPhone verification remains deferred.

Astra advised the separation of the original loss recipe from actual
tile coverage. Keep independent timing, quality, state, measured memory
and app evidence distinct in the adoption decision.

Independent Mac timing passed. The 1,024-token prefill median was 6.568 s
baseline and 5.669 s tile. Total request time fell 6.22% and the pair had
no flagged timing controls. Astra confirmed this timing subgate.
[Evidence](../benchmarks/results/2026-11-05-m9-affine-independent-v1.json).

The original loss replay and the paired tiled replay each scored all
10,000 targets. All row hashes, archived target bits, greedy IDs and NLL
agree. Mean loss is 2.884953696657687, up 0.0012285467282029394 against the
unchanged 0.05 gate. The paired sampled physical peak is 1,053,263,240 bytes.
Astra approved the collector and strict checker after four mutation controls.
[Loss evidence](../benchmarks/results/2026-11-05-m9-affine-loss-v1.json).

All 100 tasks and 6,586 sampled tokens match the accepted Mac collection.
Baseline and tile compare full distributions and state at each decision.
The pinned decoder reproduces every accepted literal completion, so the
existing 2/100 grading result applies under its unchanged gate. The sampled
physical peak was 851,494,064 bytes. Astra approved the collector and replay.
[Task evidence](../benchmarks/results/2026-11-05-m9-affine-tasks-v1.json).

The real Mac state witness passed after active tiled prefill. It verified
the charged pipeline allowance, failed publication after a synthetic invalid
private input, explicit completion replay, changed prefix, cancellation and
1,152-position rejection. Sampled physical peak was 781,698,272 bytes.
Astra approved the state and synthetic fault scope.
