# Repeated idle checks for physical task grading

The [qualified task window](../tools/experiments/task_grading_window.py) now accepts an optional `idle_check(binding)` callback for a physical producer. The existing local process/group absence, collection/raw/protected-binary hashes and idle-proof checks remain mandatory and run first. The callback runs at every existing idle boundary: initial admission, immediately before VM start, before grading, after grading and after verified VM restoration. Default callers retain the existing behavior.

This prepares the window for a later native-app response adapter that will verify installed-phone app identity and remote inference absence repeatedly. The callback alone performs no device query. A future adapter must include its callback module in `extra_source_paths` and `extra_grading_modules`, and retain private-safe hash-bound remote query evidence. A phone PID must never substitute for a local PID in the existing process checks. Literal controller/classifier, pinned Linux image/runtime policy, VM ownership/restoration and generated-program isolation remain unchanged. Window/probe/restoration paths now reject existing files and dangling symlinks before any window work.

Five added portable methods cover all five callback boundaries, remote reappearance before VM startup, remote identity failure after startup with owned restoration, mandatory local checks and dangling output admission. The final four suites pass 49 methods: 22 window, five grading, ten legacy admission and 12 v2 admission tests. All process, device and VM operations are mocked; there are no new VM runs or generated-program executions.

The first collector invocation omitted the legacy benchmark-module import path; its window suite passed and the next suite failed to import. Correcting that explicit runner environment exposed an older synthetic test fixture that omitted the added MLX shader. The final test-only fixture adds current Rust sources and, for Metal records only, current shaders while preserving historical identities and rejection of missing non-code inputs. The intermediate attempt that also added shaders to the CPU fixture is retained. Production collection admission remains strict and unchanged; no historical native evidence is requalified through these synthetic test identities.

The [qualification](../benchmarks/results/2026-10-22-remote-task-grading-window-v1.json) and [raw inventory](../benchmarks/results/2026-10-22-remote-task-grading-window-raw-v1.json) bind final and failed attempts, exact prior/intermediate sources and the unchanged literal-controller closure. The full 100-case native-app collection, decoder/response admission, actual remote checks and isolated outcome grading remain open. This does not qualify full task quality or close M8.

Astra accepted the source and completed evidence with no remaining blockers after independently verifying 124 pins, 120 raw files, 85 source copies, exact failed-attempt/source correspondence and all 49 final methods. Numerical/Swift/protected inputs, local-check precedence, ownership/restoration, links and whitespace remain verified.
